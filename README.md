# Project-part-2
פרויקט זה מציג בנייה והשוואה של שני מודלי למידת מכונה לחיזוי דירוגי סרטים:

ElasticNet: מודל רגרסיה ליניארית המזהה קשרים ישירים בין מאפייני הסרט לדירוגו.

Random Forest: מודל מבוסס עצים המזהה תבניות מורכבות ואינטראקציות לא-ליניאריות בין הנתונים.


כדי להריץ את הפרויקט, יש לפתוח את הקובץ Final_Project.ipynb. יש להתקין את כל הספריות הנדרשות בטרמינל באמצעות הפקודה: pip install -r requirements.txt. לאחר מכן, יש להריץ את כל התאים במחברת לפי הסדר (Kernel -> Restart & Run All). הקוד ייצר באופן אוטומטי את קבצי ה-requirements.txt ו-model.pkl.
